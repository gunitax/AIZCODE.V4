# AIZCODE.V4

XML-выгрузка демонстрационной конфигурации «Библиотека стандартных подсистем», редакция 3.2 (БСП 3.2.1.569, Фирма «1С»), сохраненная Конфигуратором («Сохранить конфигурацию в файлы», формат выгрузки 2.21). Режим совместимости — `Version8_5_1`, вариант встроенного языка — русский.

Репозиторий предназначен для работы ИИ-агентов и разработчиков: текстовые правки кода вносятся прямо в файлы выгрузки, прикладные доработки выполняются расширениями.

## Структура

| Путь | Содержимое |
|---|---|
| `src/` | выгрузка конфигурации: `Configuration.xml`, `ConfigDumpInfo.xml`, разделы метаданных (`Catalogs/`, `Documents/`, `CommonModules/`, `InformationRegisters/` и др.), `Ext/` (модули приложения) |
| `src/extensions/` | доработки в виде расширений: `СчетаМагазина`, эталоны `_ДемоПустоеРасширение`, `_ДемоРасширение` |
| `src/tests/` | тесты |
| `mcp-server/` | MCP-сервер `objects` (Node 22+): `find_types`, `describe_type`, `find_objects`, `read_object`, `create_object` над HTTP-сервисом объектов 1С — подробности в [mcp-server/README.md](mcp-server/README.md) |
| `build/` | собранные артефакты (`СчетаМагазина.cfe`) |
| `docs/` | артефакты процесса superpowers: спеки и планы |
| `.zcode/skills/` | скиллы для ИИ-агентов: проектные 1С (`bsl-*`, `make-extension`, `make-cf`, `make-cfe`) и библиотека superpowers |
| `AGENTS.md` | руководство для ИИ-агентов: правила работы с файлами, стиль кода БСП, запрещенные действия |

## Загрузка в Конфигуратор

1. «Загрузить конфигурацию из файлов» → каталог `src/`.
2. Обратно — «Сохранить конфигурацию в файлы» (обновляет `ConfigDumpInfo.xml`).

Требуется платформа 8.5.1+. Все текстовые файлы — UTF-8 с BOM, переводы строк CRLF: без BOM Конфигуратор не загрузит файл, состав объектов меняется только через Конфигуратор.

## Запуск MCP-сервера

```
cd mcp-server
npm install && npm run build
```

Клиент подключается через `.mcp.json` в корне репозитория (транспорт stdio, `node mcp-server/build/index.js`); адрес публикации HTTP-сервиса задается переменной окружения `OBJECTS_URL`. Подробности — [mcp-server/README.md](mcp-server/README.md).
