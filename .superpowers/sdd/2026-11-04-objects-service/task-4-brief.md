# Этап 4: `GET /object` — чтение

Источник: docs/superpowers/plans/2026-11-04-objects-service.md («Этап 4»).
Спецификация: docs/superpowers/specs/2026-11-04-objects-service-design.md
(«Чтение») — при расхождении приоритет у спецификации.

**Files:**
- Modify: `src/extensions/СчетаМагазина/CommonModules/СчетаМагазинаДанные/Ext/Module.bsl`
- Modify: `src/extensions/СчетаМагазина/HTTPServices/СчетаМагазина/Ext/Module.bsl` (обработчик `ПрочитатьОбъект`)
- Test: `src/tests/objects.http` (секция «Прочитать объект»)

**Interfaces:**
- Consumes (готово с этапов 1–3, Экспорт): `ТипПоИмени`, `Схема(Мета)`,
  `ОписаниеТипа`, `НайтиОписание`, `ДатаСтрокой`, `УникальныйИдентификаторИзСтроки`.
- Produces (этап 5, Экспорт):
  - `Прочитать(Мета, Вид, Идентификатор) → Структура|Неопределено` —
    `{id, type, kind, header, tables}`; сервисные поля: `code` у справочника,
    `number`, `date`, `posted` у документа; группа, отсутствие, недоступность —
    `Неопределено` (обработчик переводит в единый 404);
  - `Кратко(Объект, Мета, Вид) → Структура` — `{id, type, kind}` + `code` /
    `number`, `date`, `posted` по виду.

**Шаги:**

- **4.1 Запросы этапа в objects.http** (секция «Прочитать объект», стиль
  сохранить): `GET {{$dotenv OBJECTS_URL}}/object?type=Справочник._ДемоПартнеры&id={{$dotenv PARTNER_ID}}`;
  тот же UUID в ВЕРХНЕМ регистре (в URL); `id=00000000-0000-0000-0000-000000000000`;
  `id=abc`; `?type=ТакогоНет&id={{$dotenv PARTNER_ID}}`.

- **4.2 RED**: прогнать curl-ом, ожидание `501` (заглушка). Записать ответы.

- **4.3 Реализовать в `СчетаМагазинаДанные`**:
  - `Прочитать(Мета, Вид, Идентификатор)` — параметризация существующей
    `Прочитать(Идентификатор)`: таблица запроса по виду
    (`Справочник.X` / `Документ.X`), `РАЗРЕШЕННЫЕ`, право `Чтение`;
    объект-группа → `Неопределено`; `header`/`tables` — записываемые поля по
    `Схема(Мета)` с `ЗначениеJSON` (механика прежняя); сервисные поля —
    `code` (справочник) или `number`, `date`, `posted` (документ);
  - `Кратко(Объект, Мета, Вид)` — по виду;
  - `Реквизит(Мета, Имя)` — находить и стандартные реквизиты
    (`Мета.СтандартныеРеквизиты[Имя]`, затем `Мета.Реквизиты[Имя]`); убрать
    спец-случай «Дата только для счёта» (сравнение с `Документ()`); вызов
    `СчетаМагазинаМетаданные.Документ()` внутри удалить, если остался.
  Мост `Документ()`/`Схема()`-делегат в `СчетаМагазинаМетаданные` не трогать
  (потребитель — `Подготовить`, этап 5).

- **4.4 Реализовать `ПрочитатьОбъект(Запрос)`**: `type` — `ТипПоИмени`
  (параметры строки — `Запрос.ПараметрыЗапроса`); `id` — строго нижний регистр
  36 символов через `УникальныйИдентификаторИзСтроки`; не распознанный вид,
  не-UUID, `Прочитать` вернул `Неопределено` → единый `404 not_found`; иначе
  `200`.

- **4.5 Формат файлов**: BOM + CRLF байтово (полная перезапись
  `WriteAllText` с `UTF8Encoding $true`; первые байты 239,187,191 ровно один
  раз, голых LF нет).

- **4.6 Загрузка расширения** (разрешено): `tasklist /fi "IMAGENAME eq
  1cv8.exe"`; команда как в этапе 1, лог `%TEMP%\objects-load-4.log`; таймаут
  600000 мс; при таймауте — STOP, BLOCKED; успех подтверждает только 4.7.

- **4.7 GREEN**: ожидание:
  - чтение партнёра — `200`: `code` заполнен, `header.Наименование`
    соответствует, `tables` — таблицы `_ДемоПартнеры` (если есть);
  - верхний регистр UUID — `404`; нулевой UUID — `404`; `abc` — `404`;
    `ТакогоНет` — `404`;
  - регрессия: `/types`, `/type`, `/search` — `200`.
  Записать фактические ответы.

**Глобальные ограничения:** те же (правки в двух .bsl + objects.http;
русский BSL без «ё»; UTF-8 BOM + CRLF; XML не трогать; основную конфигурацию
не менять; привилегированный режим не включать; коммитов нет).
