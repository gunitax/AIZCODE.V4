# Этап 3: `GET /search` — поиск

Источник: docs/superpowers/plans/2026-11-04-objects-service.md («Этап 3»).
Спецификация: docs/superpowers/specs/2026-11-04-objects-service-design.md
(«Поиск») — при расхождении приоритет у спецификации.

**Files:**
- Modify: `src/extensions/СчетаМагазина/CommonModules/СчетаМагазинаДанные/Ext/Module.bsl`
- Modify: `src/extensions/СчетаМагазина/HTTPServices/СчетаМагазина/Ext/Module.bsl` (обработчик `НайтиОбъекты`)
- Test: `src/tests/objects.http` (секция «Найти объекты»)

**Interfaces:**
- Consumes (готово с этапов 1–2, Экспорт): `ТипПоИмени(ИмяТипа)` →
  `{Мета, kind}`; `ПравоДоступа` платформы.
- Produces (этап 5, Экспорт):
  - `НайтиОбъекты(Мета, Вид, СтрокаПоиска, Лимит) → {items, hasMore}` —
    поле поиска: `Номер` для документов (`kind = "document"`), `Наименование`
    для справочников; запрос с `РАЗРЕШЕННЫЕ`, без помеченных на удаление и
    групп (`НЕ ЭтоГруппа` для иерархии групп, как в существующем
    `УсловиеЭлементов`), выбор не более `Лимит + 1`, сортировка
    «поле поиска, ссылка»; элемент — `{id, name}`; `name` — наименование
    (справочник) или номер (документ); `hasMore=true`, если после `Лимит`
    записей выборка не исчерпана;
  - `СсылкаДоступна(Мета, Ссылка) → Булево` — обобщённая вместо
    allowlist-версии: право `Чтение` на мету, существование, `НЕ
    ПометкаУдаления`, не группа (справочники); запрос с `РАЗРЕШЕННЫЕ`.

**Шаги:**

- **3.1 Запросы этапа в objects.http** (секция «Найти объекты», стиль файла
  сохранить): `GET {{$dotenv OBJECTS_URL}}/search?type=Справочник._ДемоПартнеры&q=Альфа`;
  `…&q=%`; `…&limit=0`; `…&limit=101`; `…&limit=abc`; `?type=Справочник._ДемоПартнеры`
  без `q`; `?type=ТакогоНет&q=а`; `?type=Справочник.Пользователи&q=а`;
  `?type=Документ._ДемоРеализацияТоваровУслуг&q=0&limit=1` (пустая выдача —
  валидный ответ; содержательный поиск документа по номеру проверяется в
  этапе 5/6 по номеру созданного счёта).

- **3.2 RED**: прогнать curl-ом, ожидание `501` (заглушка). Записать ответы.

- **3.3 Реализовать обработчик `НайтиОбъекты(Запрос)`**:
  - `type` отсутствует или `ТипПоИмени` не распознал → `400`, `error.code =
    "unknown_type"`;
  - `q` — непустая после `СокрЛП`, иначе `400 invalid_request` (в details —
    `null` путь, сообщение о пустой строке поиска);
  - `limit` — необязательный; по умолчанию 20; целое 1–100
    (существующий помощник `Цифры` + проверка диапазона), иначе
    `400 invalid_request`;
  - нет права `ПравоДоступа("Чтение", Мета)` → `403 forbidden`;
  - ответ `200` — `НайтиОбъекты(Мета, Вид, СтрокаПоиска, Лимит)`.

- **3.4 Реализовать в `СчетаМагазинаДанные`**: `НайтиОбъекты(Мета, Вид,
  СтрокаПоиска, Лимит)` — переработка существующей `НайтиВСправочнике`
  (шаблон через `ОбщегоНазначения.СформироватьСтрокуДляПоискаВЗапросе` +
  `СПЕЦСИМВОЛ "~"` сохранить — символы `% _ [ ^` литеральные); поле поиска и
  сортировка зависят от `Вид`; `СсылкаДоступна(Мета, Ссылка)` — обобщить
  (таблица запроса по виду: `Справочник.X` / `Документ.X`; для справочника —
  `НЕ ЭтоГруппа` в иерархии групп), удалить allowlist-зависимости:
  `РазрешенныеСправочники()` и `ДобавитьСправочники()` в
  `СчетаМагазинаМетаданные` (последний их потребитель — этот модуль) —
  координация: правку метаданного модуля (удаление двух функций) сделать в
  этом этапе, файлы этапа расширены этим удалением.
  Вызов `СсылкаДоступна` в `Преобразовать` обновить: мету резолвить из
  описания типа (`Метаданные.Справочники[Описание.catalog]` — механика прежняя,
  имя из описания, не из пользовательской строки).

- **3.5 Формат файлов**: BOM + CRLF **байтово** (инцидент двойного BOM
  этапа 2: проверять первые 3 байта = 239,187,191 ровно один раз, голых LF
  нет; нормализация — только перезапись целиком, без дописывания).

- **3.6 Загрузка расширения** (разрешено): `tasklist /fi "IMAGENAME eq
  1cv8.exe"`; команда как в этапе 1, лог `%TEMP%\objects-load-3.log`; таймаут
  600000 мс; при таймауте — STOP, BLOCKED (не ретраить); успех подтверждает
  только 3.7.

- **3.7 GREEN**: ожидание:
  - `q=Альфа` по `_ДемоПартнеры` — `200`, `items` содержит `id` = `PARTNER_ID`
    из `.env`;
  - `q=%` — `200`, `items: []` (символы шаблона — литералы);
  - `limit=0|101|abc` — `400 invalid_request`;
  - без `q` — `400 invalid_request`;
  - `type=ТакогоНет` — `400 unknown_type`;
  - `Пользователи&q=а` — `200` (читаемо пользователем);
  - документ-поиск по `q=0&limit=1` — `200` (пусто или находки по номерам).
  Записать фактические ответы.

**Глобальные ограничения:** те же (правки в `СчетаМагазинаДанные`, HTTP-модуле,
`objects.http` плюс удаление двух функций в `СчетаМагазинаМетаданные`;
русский BSL без «ё»; UTF-8 BOM + CRLF; XML не трогать; основную конфигурацию
не менять; привилегированный режим не включать; коммитов нет).
