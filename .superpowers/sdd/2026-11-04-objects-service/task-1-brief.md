# Этап 1: `GET /types` — реестр типов

Источник: docs/superpowers/plans/2026-11-04-objects-service.md («Этап 1»).
Спецификация контракта: docs/superpowers/specs/2026-11-04-objects-service-design.md
(«Маршруты», «Описание типов», «Разрешение на создание») — при расхождении
приоритет у спецификации.

**Files:**
- Modify: `src/extensions/СчетаМагазина/CommonModules/СчетаМагазинаМетаданные/Ext/Module.bsl`
- Modify: `src/extensions/СчетаМагазина/HTTPServices/СчетаМагазина/Ext/Module.bsl` (обработчик `НайтиТипы`)
- Test: `src/tests/objects.http` (секция «Найти тип»)

**Interfaces (produces — используют этапы 2–5, поэтому все функции Экспорт):**
- `ИмяТипа(Мета) → Строка` — `"Справочник.X"` / `"Документ.X"`;
- `ТипПоИмени(ИмяТипа) → Структура|Неопределено` — `{Мета, kind}`
  (`kind = "catalog"|"document"`);
- `РеестрТипов() → Массив` структур `{name, kind, title, creatable}` —
  все справочники и документы конфигурации;
- `ДопустимКСозданию(Мета) → Булево` — `СтрНачинаетсяС(Мета.Имя, "_Демо")`
  или `Мета.Имя = "Валюты"`.

**Steps:**

- **1.1 Запросы этапа в objects.http**: секция «Найти тип» — три запроса
  `GET {{$dotenv OBJECTS_URL}}/types` — без `q`; `?q=валют`; `?q=поступлен`.
  Отделять новые запросы разделителями `###` с комментариями, стиль файла
  сохранить.

- **1.2 RED**: прогнать запросы curl-ом (заголовок `Authorization` — значение
  `OBJECTS_AUTH` из `src/tests/.env`; базовый URL — `OBJECTS_URL`).
  Ожидание: `501 not_implemented` (обработчик-заглушка). Записать фактический
  ответ (статус + тело) для отчёта.

- **1.3 Реализовать четыре функции** в `СчетаМагазинаМетаданные` по сигнатурам
  из Interfaces. Реестр — перебор `Метаданные.Справочники` и
  `Метаданные.Документы`; `title` — `Представление()`.
  Существующие функции `Документ()`, `Схема()`, `РазрешенныеСправочники()`,
  `ОписаниеПоля()`, `ОписаниеТипа()`, `ДобавитьСправочники()` не трогать —
  их трогают последующие этапы.

- **1.4 Реализовать `НайтиТипы(Запрос)`**: параметр `q` — обрезать внешние
  пробелы (`СокрЛП`); пустой/отсутствующий — все виды; фильтр — вхождение
  без учёта регистра в `name` или `title`; сортировка по `name`; ответ `200`
  через существующий `ОтветJSON` (`{"types":[…]}`).

- **1.5 Проверить формат файлов**: у каждого изменённого файла — UTF-8 BOM
  (первые байты 239,187,191) и отсутствие «голых» LF. Нормализация:
  `$t=[IO.File]::ReadAllText($p); $t=$t -replace '(?<!\r)\n',"`r`n"; [IO.File]::WriteAllText($p,$t,(New-Object System.Text.UTF8Encoding $true))`

- **1.6 Загрузка расширения** (разрешено пользователем):
  - `tasklist /fi "IMAGENAME eq 1cv8.exe"` — чужие процессы можно завершать,
    кроме процесса в активной загрузке;
  - команда (версию платформы взять последней из `C:\Program Files\1cv8\*\bin\1cv8.exe`;
    запуск через PowerShell `&`, таймаут команды 600000 мс):

    ```
    & "<путь>\1cv8.exe" DESIGNER /F "C:\Users\sax\Documents\InfoBase20" /N Администратор /LoadConfigFromFiles "Q:\AIZCODE.DZ3\src\extensions\СчетаМагазина" -Extension СчетаМагазина /UpdateDBCfg /Out "%TEMP%\objects-load-1.log"
    ```

  - лог — без сообщений об ошибках; пустой `/Out` — не признак успеха/неудачи;
    УСПЕХ ПОДТВЕРЖДАЕТ ТОЛЬКО ШАГ 1.7;
  - если команда упёрлась в таймаут — STOP: не ретраить, записать BLOCKED
    в отчёт (база могла остаться посреди загрузки).

- **1.7 GREEN**: прогнать запросы этапа. Ожидание:
  - полный список: `200`; есть `Справочник._ДемоПартнеры` и
    `Документ._ДемоСчетНаОплатуПокупателю` с `creatable: true`;
    `Справочник.Пользователи` — `creatable: false`;
  - `q=валют` — `Справочник.Валюты` (и совпавшие по синониму);
  - `q=поступлен` — `Документ._ДемоПоступлениеТоваровУслуг`.
  Записать фактические ответы (статус + тела) для отчёта.

**Глобальные ограничения, связывающие этап:**
- правки только в перечисленных файлах; XML расширения не трогать;
- русский BSL, вместо «ё» — «е» (включая тексты сообщений);
- UTF-8 с BOM, CRLF во всех изменяемых файлах;
- основную конфигурацию не менять; привилегированный режим не включать;
- коммитов нет (нет git) — фиксация: чекбоксы плана и отчёт.
