# MCP-сервер «objects»

## Назначение

Локальный MCP-сервер `objects` — пять инструментов над HTTP-сервисом объектов 1С:
`find_types`, `describe_type`, `find_objects`, `read_object`, `create_object`.
`create_object` — изменяющий инструмент (`readOnlyHint: false`), остальные только
читают базу. Транспорт — stdio: клиент запускает `build/index.js` как дочерний
процесс и общается с ним по стандартным потокам.

## Сборка

Требуется Node 22+.

```
npm install && npm run build
```

Артефакт сборки — `build/index.js` (каталог `build/` в git не коммитится).

## Подключение

Проектная конфигурация MCP — файл `.mcp.json` в корне репозитория:

```json
{ "mcpServers": { "objects": { "command": "node", "args": ["mcp-server/build/index.js"] } } }
```

Если формат не будет принят клиентом — запасной вариант:

```
zcode mcp add objects -- node mcp-server/build/index.js
```

## Конфигурация

Подключение к сервису объектов 1С задается переменными окружения:

- `OBJECTS_URL` — базовый адрес публикации HTTP-сервиса, например
  `http://host/bsp-demo2/objects`;
- `OBJECTS_AUTH` — готовое значение заголовка `Authorization`, например `Basic …`.

Если переменные не заданы, сервер читает файл `src/tests/.env` (ищет его вверх
по дереву каталогов от своего файла). Нет ни переменных, ни файла — сервер
завершается с ошибкой старта и подсказкой. Секреты в конфигурации MCP
(`.mcp.json`) не хранятся.

## Тесты

- `npm test` — юнит-тесты, без сети.
- `npm run test:e2e` — локальный stdio-smoke собранного `build/index.js` и E2E
  живого сервиса. E2E создает объекты в живой базе — согласовано пользователем,
  см. спеку, раздел «Тестовые данные».

## Инструменты

| Имя | Назначение | Изменяющий |
|---|---|---|
| `find_types` | Поиск типов объектов по части названия (вызывается первым, чтобы узнать точное имя типа) | нет |
| `describe_type` | Описание типа: реквизиты шапки и табличные части с колонками | нет |
| `find_objects` | Поиск объектов заданного типа по подстроке названия, возвращает `id` объектов | нет |
| `read_object` | Чтение объекта целиком: шапка и табличные части | нет |
| `create_object` | Создание справочника или непроведенного документа | да (`readOnlyHint: false`) |
